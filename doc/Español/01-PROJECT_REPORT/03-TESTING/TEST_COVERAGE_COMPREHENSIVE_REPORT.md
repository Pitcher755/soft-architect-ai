```dart
// File: tests/client/unit/features/settings/presentation/providers/settings_provider_test.dart

  'should load persisted settings on initialization',
  () async { ... },
  skip: 'SharedPreferences mock cannot be reset inside individual test. Requires separate test file.',

```

**Reason:** SharedPreferences mocking limitation in Flutter prueba framework. The `setUp()` method initializes SharedPreferences with empty values for the entire prueba group. Individual pruebas cannot override this initialization without creating a separate prueba archivo or using integration pruebas.
