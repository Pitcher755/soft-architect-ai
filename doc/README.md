## 📝 Notas Importantes

### Para Desarrolladores
- Toda la documentación técnica está en `/doc/Español/` y `/doc/English/`
- Los archivos originales en la raíz de `/doc/` se mantienen como respaldo
- La estructura es completamente simétrica entre idiomas

### Para Usuarios Finales
- Empieza con [Quick Start](Español/04-USER_GUIDE/01-QUICK_START.md)
- Todos los documentos del usuario están en `/doc/Español/04-USER_GUIDE/`
