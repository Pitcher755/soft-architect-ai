# 📚 Project Ontology and Ubiquitous Language

This document defines the fundamental terms that **SoftArchitect AI** and the Human Team will use to communicate. Avoids ambiguities.

## Core Concepts (Meta-System)

### **Tech Pack**
A curated set of rules, folder structures, and code snippets for a specific technology (e.g., `python-fastapi`). It is the technical "source of truth".

### **Gate (Quality Gate)**
Mandatory checkpoint at the end of each Phase. The system automatically validates the existence and quality of required documents before unlocking the next phase.

### **Golden Template**
Master template located in `01-TEMPLATES`. Contains the ideal structure of a document. The AI must fill in the gaps (`{{VAR}}`) without altering the structure.

### **Context Window**
The totality of information the AI "knows" about the project at a given moment. It is fed from the `.md` files generated in the `context/` folder.

## Engineering Definitions

### **Snapshot**
Frozen state of the project at a point in time (e.g., MVP, V1).

### **Artifact**
Any file generated by the process (Document, Diagram, Code).

### **Hardening**
Process of securing the system. In SoftArchitect, we apply hardening *before* writing code (in the design phase).
